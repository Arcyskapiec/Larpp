# Larpp
Larp application

#cel
zebranie informacji larpowych w jednym miejscu oraz ujednolicenie kanałów komunikacyjnych dla zorganizowanych oddziałów larpowych oraz wydarzeń

#funkcje
F01 zapisywanie i porządkowanie informacji o postaciach graczy oraz oddziałach (wyświetlanie oraz uzupełnianie wprowadzonych przez użytkowników informacji z różnym dostępem do wyświetlania tych informacji dla różnych postaci)
F02 obsługa wydarzeń larpowych (tworzenie wydarzenia, obsługa formularzy zgłoszeniowych) 
F03 wyszukiwarka wydarzeń, oddziałów oraz postaci 
F04 zakładanie i obsługa konta oraz profili różnych postaci
F05 wyświetlanie mapy i terminów wydarzeń
